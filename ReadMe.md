# 📝 Simple Notes App

A simple RESTful Notes API built using **FastAPI**, **PostgreSQL**, and **SQLAlchemy**.  
The application allows users to create, read, update, and delete notes.

## 🚀 Features

- Create a new note
- Get all notes
- Get a note by ID
- Update an existing note
- Delete a note
- PostgreSQL database integration
- SQLAlchemy ORM
- Pydantic data validation
- Swagger API documentation

## 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **PostgreSQL**
- **SQLAlchemy**
- **Pydantic**
- **JWT**
- **Uvicorn**
